# 本机测试凭据持久化设计评审

版本：0.1 · 2026-09-19 · 状态：实施完成，门禁通过

## 变更概览

- 目标：允许 macOS 开发环境把 DeepSeek 测试密钥长期保存在系统 Keychain；`npm run dev` 在未显式提供 `DEEPSEEK_API_KEY` 时读取该凭据。
- 非目标：把密钥写入仓库、普通配置文件、日志或 Renderer；为 Windows/Linux 伪造不安全的明文持久化；增加登录页或生产凭据管理 UI。
- 影响模块：开发启动器、开发凭据边界、Agent 测试与运行文档。
- 当前版本验收标准：环境变量优先；Keychain 仅在 macOS 开发启动时读取；读取失败不崩溃且沿用现有缺失凭据提示；Vite 子进程不继承 provider 密钥；测试密钥不出现在 Git 内容中。
