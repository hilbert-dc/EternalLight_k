# 创作方法注册与冻结绑定

目标：落实理想架构 L3/A0。删除启动时递归读取全部 Skill 并拼进每个模型请求的路径，由 Rust 在普通任务创建事务中冻结方法、版本、正文 digest、来源快照、任务目标与路由策略。继续复用现有 Task/Step/Attempt、Context Pack、Codex 和候选权限，不另建调度器或供应商接口。

## 当前版本契约

- 注册表只包含工程中可审阅的内置方法，编译时读取产品 `codex-runtime/skills/` 文件。不从作者正文、远程 URL、源 EternalLight 目录或模型输出加载执行指令。
- `novel-workflow` 为必需执行契约，发布状态 stable 只表示该契约已维护并通过行为测试，不表示文学质量已认证。专用 `novel-canon`、`narrative-ir`、`story-tests` 保持 candidate，默认不加载；Author 创建任务时显式提供 `experimentalMethods` 才可使用匹配任务的候选方法。最多两个，重复、未知或不匹配的选择整笔拒绝。
- 每个方法有 id、version、digest、kind、status、requiredContextKinds、outputSchemaRef、limitations 和正文；冻结绑定还包含 taskId、projectId、snapshotId、inputRevision、operation、intentGeneration、targetDigest、routingPolicyDigest、执行模式及工具作用域。正文及绑定摘要一起存入现有 inputManifest，不能由调用方伪造 binding。
- 每方法最多 12 KB UTF-8，全部方法最多 20 KB；方法计入完整请求及 Context Pack 的已有总预算，不获得额外上下文额度。可选内容可裁剪，但必需方法不能被悄悄删除；预算不足明确拒绝。
- 更新方法文件只影响随后新建的任务。已创建任务继续使用持久正文及 digest，不按磁盘当前内容重新路由，也不把任务创建时快照冒充之后的正文检查点。历史读取核验冻结内容完整性，不追认新的目录版本。
- 普通失败步骤的重试若未指定新方法选择，继承前一 Attempt 的作者选择；每次创建新绑定并保留旧 Attempt。作者显式传空列表才撤回实验选择，不因恢复操作悄悄丢失已选技法。当前注册表若不再允许所选方法则拒绝新任务，不替作者换包。
- Host 只取 Runtime 的冻结方法；规划深审、普通候选、知识抽取、自由对话均使用同一绑定。steer 只追加作者要求，不重新注入全部方法或改变绑定。方法不授予工具、正式采用或独立审查权限；执行模式记录 engineManaged，子 Agent 仍归原引擎能力与预算控制，方法绑定不禁用也不虚报它们。
- `Context Pack.creativeCapabilityBinding` 返回同一绑定，内容哈希与整体预算覆盖它；不再只靠提示词宣称方法已加载。

## 验收与边界

真实仓储和 HTTP 验证默认路由、显式实验、错误选择回滚、重开恢复、冻结正文完整性、同任务上下文一致性、候选越权拒绝与预算不足。Host 验证实际生成使用绑定而非目录扫描，缺失或被破坏的冻结方法不得启动；已有真实受控 Codex 回环继续验证执行链。

这不是 A1–A3 全部完成：尚无新技法质量实验、自然语言方法推荐、动态子 Agent 分工、题材包及作者盲评，不能把 candidate 升为稳定文学方法。只读角色仍由原操作权限控制，方法文字不构成权限。

实施前由实现者按架构、技术可靠性、测试、产品与 UX 五方面自检，不召集独立评审。当前 schema 直接实现新契约，无旧格式兼容、迁移或第二绑定权威。

## Skill 规范复核

使用 skill-creator 对现有四个文件做适用范围与结构复核：保留简单、自包含的入口，不增加无用目录或自动发现策略变更；删除“正文只是 IR 渲染”“Canon 单独成为无来源真相”等与目标架构冲突的要求。必需执行契约压缩到约 2.4 KB，专用方法各不足 1 KB，不复制通用模型提示词或要求额外审批。四个文件通过官方 quick_validate（使用缓存 PyYAML；未修改系统 Python 或工程依赖）。此校验只证明声明结构有效，不证明文学行为质量。

## 实施验证记录

`CARGO_NET_OFFLINE=true npm run verify` 完整通过，覆盖前端构建、Rust 领域与 Runtime、引擎与委派、发布门禁、136 项 Agent 测试和 10 项 UI 测试；独立 native 工作区严格 Clippy 通过。新增真实仓储测试验证默认与显式选择、错误选择原子回滚、重开后的冻结记录、损坏拒绝与同一步骤重试继承。HTTP 测试验证作者选择、模型端越权拒绝、绑定进入 Context Pack 以及总预算不足明确失败；Host 测试验证缺失或损坏绑定不能执行。

必需方法计入预算后，旧的 16 KB 成功场景已无法容纳原有目标与新契约；成功用例调整到 20 KB，仍验证可选内容截断，小预算用例仍拒绝。不通过删除方法正文规避预算。实验方法当前通过 Author HTTP 接口选择，尚无 UI 选择器；本轮未进行真实供应商文学质量认证或 Windows 实机验证，构建的大包体警告仍存在。以上是 L3/A0 完成证据，不是全部理想架构完成声明。
