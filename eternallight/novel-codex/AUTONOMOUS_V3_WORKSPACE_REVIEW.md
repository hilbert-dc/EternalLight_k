# v3 开放作品工作区与有界长篇读取评审

日期：2026-10-07。范围：B/D 的来源引用、按问题读取和实际依赖。实施前记录；五视角是同一实现者的审查，不冒称五名独立人员。

## 目标与边界

评估任务构造只交付当前稿、前稿和标准的有界材料，以及冻结版本的工作区入口；不复制全部前章正文。工作区目录按元数据分页，模型可按对象、章节或问题定位获准资料，再用现有来源工具读取所选原文。每次响应保持现行模型 item 大小限制，来源证据仍绑定实际可见文本和当前身份。

工作区是已有领域存储的访问视图。Native 从持久 task 派生权限，目录不授予写入、采用、发布、任意历史读取或跨作品访问。Writer 的未来章节、POV 隐藏内容及受限场景不因新入口开放。当前稿、修改前稿、前文、规划和假设明确标用途，规划和推断不成为正文事实。

拟复用 `read_source_content`，新增 `view=workspace` 的有界目录/检索入口，结果提供本 task 所有的稳定 sourceId；所选正文仍通过现有 parsed/raw 读取。引用目录只保留对象与修订身份，正文在实际读取时懒加载并冻结为现有 task source 投影。读取记录针对每个来源对象的实际返回范围，不以整个作品的第一个未读位置要求全书扫描。目录、检索命中与已理解分开表达。

独立评估始终核对当前稿、作者标准和 Native 派生目标；不能用未读作为绕过必需标准的理由。对其实际读取的前文或规划建立来源依赖；相关源改变导致报告失效，无关后续章节变化不应令独立评估整体失效。保留当前稿/标准/锁定与未选内容的原校验。报告提交与已存报告的新鲜度需由其拥有者接入依赖核对。

## 当前版本验收

- 千章作品的评估资料构造不加载、复制或序列化全部前章正文；目录每页和原文每页均有界。
- 可明确定位并读取远章的实际冻结正文；未读远章仍是未知，不宣称无相关事件。
- 目录或检索响应不登记为全文阅读；对象内分页、压缩后返回范围和原任务身份有效。
- 跨 task、跨项目、伪造 sourceId、错误 cursor、POV/未来及范围越界拒绝。
- 当前稿改变、实际依赖的前文改变使评估失效；未依赖的后章改变不使它失效。
- schema、工具说明、Runtime、Core、fixture 和测试一次同步。原文证据、作者标准和保护内容不放松。

## 实施后五视角复核

2026-10-07，B/D 生产冻结。独立评估的构造不再复制全部前章正文。Task 工作区分页提供当前稿、冻结修改前稿、前文和规划的具体版本引用；目录/检索不算正文已读。主任务和可信直系协作调用分别记录真实阅读者，协作分页不能冒充主任务的原作者要求或保护范围已读。每个实际读取的工作区来源保留依赖；当前稿与必需作者标准仍独立验证。原作者完整原话是可分页来源，提交评估/最终交付必须有主任务完整读回，引文纠正须实际读回、同 Work、当前作者文本和准确 hash。
