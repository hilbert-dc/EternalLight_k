# 通用内容选区对话

## 变更概览

- 目标：作品内所有可见文档内容（简报、大纲、章纲、正文、人物、设定、时间线、伏笔和版本内容）均可划选后加入对话；编辑框与阅读区共用入口，支持多段引用和未保存文本。
- 非目标：操作系统任意文件浏览器、二进制文件解析、自动写回选区。
- 影响模块：Renderer 选区捕获、对话草稿、引用卡片；Electron 上下文校验与提示；Rust 候选任务及后续创作授权。
- 验收：原文不截断；来源、版本和未保存状态可见；跨页、跨作品、重试保留原引用；引用本身不是写入授权；未保存文本讨论不覆盖本地编辑。

## 实施后复核

### 实际交付

- 文档边界统一捕获 DOM Range 与原生文本输入选区，提供“加入对话”和 Cmd/Ctrl+L；正文锁定使用只读输入，不阻止选区。八类页面、规划版本浮层与已保存分析均有内容边界和来源标记。
- 草稿引用卡片支持多段、展开原文、移除、跨作品隔离，添加不覆盖问题；本轮与较早对话保留已发送引用。失败重试发送原始冻结引用，不消费下一轮草稿。
- Renderer 与 Electron 共用严格引用契约和数量/字符/字节/token 预算。Electron 在创建任务前验证作品归属，并核对持久化后的 focus；捕获文字作为引用数据进入模型上下文，不当作系统指令或数据库已核实事实。
- 未保存内容、或本地编辑未保存时发送的引用讨论只读：宿主跳过候选执行/持续创作，Rust 拒绝候选任务登记与后续生成交接。本地编辑不自动保存、不被回复覆盖。
- 版本浮层中加入引用后关闭浮层并聚焦对话输入；引用区独立于历史滚动，不被长对话挤压。README 已同步使用方式、预算和能力边界。
