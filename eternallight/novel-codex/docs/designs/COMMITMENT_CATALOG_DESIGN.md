# 独立承诺目录与目标章快照

## 目标与边界

全作品独立承诺必须可被作者分页找回，不依赖当前章提取报告；新报告不得使旧报告建立的长期对象在界面失踪。列表按不可变 snapshot 固定对象成员和当前选中修订；继续分页不混入后来创建或改写的内容。列表只是发现入口，打开对象仍取当前 Author detail，写入继续复用候选保存和 Review，不能用旧列表授权写入。

同时纠正上一轮验证不足：UI 可选无正文章节，但领域 window 校验仍只读 draft。当前 schema 增加快照章目录投影，在创建快照时捕获当前目录。历史目标位置只能读取该快照的正文或捕获目录，不读后来目录；写入校验在既有事务/CAS 内读取当前目录及正文，不能引用不存在、跨作品或倒序章节。正文仍是唯一证据来源；未起草章目录不是证据或已发生事实。

## 实施契约

- Author-only GET commitments：limit 1–20，cursor 为当前格式的 JSON，硬长度上限；包含 projectId/snapshotId/afterObjectId/limit。按 objectId keyset，SQL 先限定 snapshot/project/kind，再 LIMIT；不可跨作品、跨 snapshot 或变更 limit 接续。
- 响应 data 只含 id/summary/kind/status/revisionId/confirmationState/sourceCurrent；snapshotId 和 nextCursor 明确返回。summary 的领域上限已有 500 字，不携带所有正文锚点或可写 Author 控制信息。固定快照完整遍历不宣称语义完整。
- Electron 严格校验分页参数，Candidate/MCP 不增加该全局读权限。UI 按需读取，每页 20 项，内存保留最近 200 行；继续分页时收起早期行并明确提示，不以 200 项阻止访问后续对象。迟到请求按作用域和序号隔离。刷新重新开始一个快照，旧页不与新页混合。
- 列表选择复用现有独立承诺详情/编辑/确认；未知写入结果仍按原请求核对，未保存正文和编辑期间不切换选择。
- 不加旧 schema 迁移、双轨、供应商分支、独立写入权威或任务执行器。

## 实施前五方面自检

依用户要求由实现者单独自检，不组织评审或子 Agent。架构：列表是快照派生发现服务，模型投影与写入权限保持原边界。技术 A：固定快照 keyset、跨作品校验、有界消息及写入事务。技术 B：真实仓储和 Author HTTP 分页/权限/历史测试，Electron 展示与迟到响应验证。产品：旧报告对象仍可调整，目标章可提前安排。UX：按需全局目录、空/失败/部分加载区分，正文源失效不隐去承诺。

验收须证明无正文章节窗口真正落库、后来目录变化不污染历史位置，固定页不漏不重、不混后续修订、跨作品和越权拒绝，以及旧报告独立对象可从 UI 打开。完整对话更新、自动创作循环提取、语义检索和 S1–S5 完整验收仍不包含在此轮完成声明中。

## 实施后验证

已实现独立 Rust 目录模块、同一读事务内复用的承诺详情投影、Author HTTP、Electron/preload/类型，以及折叠的全作品目录。继续加载使用固定快照 cursor，超过 200 项时收起早期已加载结果而不阻止继续访问；未保存编辑期间不能切换对象。快照章目录由当前 schema 的创建快照触发器捕获，没有旧库回填或升级逻辑；写入依现有事务读取当前正文/目录并核验正数和顺序，历史位置只读冻结来源。

最终 `CARGO_NET_OFFLINE=true npm run verify` 退出 0，包含 Rust 领域与 Runtime 全套、引擎、委派回环、发布门禁、139 项 Agent 和 11 项 UI。新增真实仓储场景覆盖无正文章节窗口落库、历史位置不受后来正文影响、倒序/不存在/非正章次拒绝及事务不变；固定快照分页不混入新对象和后来修订，页长/游标范围拒绝。现有报告替换测试增加独立对象目录找回断言。真实 HTTP 校验响应投影、Author-only 权限和页长，桌面 IPC 校验实际查询参数转发。

Electron 用例覆盖失败刷新、跨页保留固定快照、当前章无报告时打开旧报告对象的当前详情、过期证据拒绝确认、迟到读取隔离，以及 220 项分页后的 200 行滚动内存上限。初轮新增迟到测试误点旧 DOM：现在等待新章节目录节点实际挂载，再发起请求，不靠延长超时掩盖。已检查实际隔离 Electron 目录截图；它不证明整篇作品旅程、Windows 实机或文学质量。

实施者五方面自检：单一候选/Review 权威不变，目录不带实时写授权；模型全局权限未扩大；消息与 UI 内存有上限，来源失效仍明确；协议/调用方/fixture 同轮更新，没有兼容、双写或供应商分支。当前历史窗口只捕获章号，不宣称完整章节目录撤销/重排语义已验收；全局语义检索、完整对话更新、自动创作派发与 S1–S5 原门槛继续保留。已有前端大包体警告仍在。
