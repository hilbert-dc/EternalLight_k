# 作品多对话理想方案

2026-10-06 · 当前目标架构，非历史兼容方案。

2026-10-09 后续目标见 [对话任务启动停止与临时切换设计](CONVERSATION_TASK_CONTROL_DESIGN.md)：按对话独立执行、停止接续和临时插问。下文保留的全局执行锁属于本阶段实现边界；后续方案尚未实施，不改变本记录的验收范围。

## 变更概览

- 目标：作品是共享事实空间，对话是独立意图与聊天历史空间。用户能新建、切换、恢复、命名、搜索、置顶、归档对话；选区可加入当前或新对话；从历史回合开启分支。
- 非目标：此次不重建 Codex 会话内核，不授予聊天直接采用正文的权限，不承诺并行模型写入；既有全局执行锁保留，浏览与编辑草稿不应被执行锁阻塞。
- 依据：Codex Projects/chats 与 App Server thread/start,resume,fork；Cursor 显式引用与侧聊。参考 https://learn.chatgpt.com/docs/projects 、https://learn.chatgpt.com/docs/app-server 、https://cursor.com/docs/agent/overview 。
- 边界：作品 → 对话 → 回合；WorkTask 是回合产生的可审计创作执行，不是对话本身。切换不保存正文、不取消任务、不回滚正文、不将别的聊天历史隐式注入上下文。

## 架构与状态

1. Rust SQLite 作为作品归属、标题、置顶、归档、分支来源的唯一事实源。空对话登记即可列出；线程 ID 全局唯一、作品归属不可变。聊天全文仍由现有引擎持久化，不复制另一套 transcript。
2. Renderer 明确选择 threadId；发送冻结该 ID，重试回原线程；宿主验证归属及可发送状态再创建任务/模型回合。新建/分支使用现有 thread/start,fork，绝不借用最新线程。
3. 草稿、引用、临时消息与失败信息以作者×作品×线程隔离。本机持久化草稿，容量与引用预算仍需验证，不能静默淘汰。任务事件持续归属原执行；选中其他聊天仅改变阅读与草稿。
4. 执行中允许浏览其他聊天；新建/fork/resume/send和归档运行线程受全局锁保护。非运行聊天显示原执行名称与返回入口，禁止出现原任务停止/授权/批准按钮。
5. 新建/切换失败留在原对话；旧阅读不能挂新标题；已归档只读且可恢复。metadata 乐观版本，失败不虚报成功。线程创建登记失败保留可重试登记，不能重复创建。

## 理想交互与本轮验收

- 左栏“对话 ＋新建”、标题搜索、最近/已归档切换，置顶优先，独立滚动。
- 右栏显示当前对话标题，只有当前对话的消息、引用和输入；新对话空态明确作品资料共享、聊天历史独立。
- 选区浮条提供加入当前与新对话讨论；失败保留原内容。
- 回合分支复用 thread/fork(lastTurnId)，不扩大继承范围，不复制写入授权。
- 多个空线程重启可见；A/B 草稿与引用隔离；跨作品拒绝；运行 A 时浏览 B 不取消且不能误操作 A；失败重试冻结 A；未保存选区只读保护沿用。
- 并行模型执行、跨对话显式引用与全文语义搜索属于后续独立能力，不以本轮宣称已完成。

## 实施后复核

### 实际交付

- 原生 `story_conversations_v1` 登记空对话、不可变作品归属、手工标题、置顶、归档和精确分支来源；乐观版本及创建登记幂等。作者管理路由不开放为模型 MCP 工具，不修改作品正文修订。
- 真实 Electron preload → Host → Runtime/引擎一次性贯通：新建、读取、重命名、置顶、归档/恢复；发送显式线程 ID；已归档/跨作品在模型调用前拒绝。管理操作和模型执行共用互斥边界，管理元数据不依赖模型可用性。
- 左栏可创建、真正切换与继续聊天；空态、加载、失败重试、搜索、置顶、归档、运行中返回入口齐全。去除 App 中已废弃的只读历史主入口，不保留隐藏双轨交互。
- 作者×作品×线程本机保存输入及引用；首条发送登记完成后才绑定线程，同时保留等待期间的下一条未发送草稿。旧读取、旧输入闭包和重试不能污染其他对话。
- 运行中可浏览其他对话并编辑草稿，不取消原执行。消息、已有 WorkTask、创作建议及任务细节按所选对话或精确执行来源隔离；停止、授权与审批不得挂到另一个对话。
- 所有既有内容视图继续支持选区讨论；浮条新增“新建对话讨论”。失败保留选区供重试；未保存选区继续冻结原文并保持只读约束。
- 历史读取及已完成当前/历史回合可创建分支，调用 `thread/fork(lastTurnId)`；不复制未发送草稿、引用或作者写入授权。Runtime 沿同作品不可变分支祖先还原原作者消息，严格裁剪每层来源回合；不能确定绑定的来源不回退到模型拼装提示。

### 明确边界与后续理想态

1. 当前搜索针对对话标题（当前展示摘要为空）；全文搜索、跨对话显式引用为后续独立功能，不提供假入口。
2. 当前沿用引擎回看预算：最近 12 回合及既有文本/执行项上限；更长历史分页为后续产品能力，不宣称全文无限回看。
3. 全局模型执行仍串行；浏览及草稿独立不等于并行写入。后续先支持并行只读研究，再为候选写入设计作品版本冲突与明确采用流程。
4. 引擎创建与 Runtime 登记不是跨服务原子事务。Host 存活期间保留登记重试，避免重复创建；两服务之间进程崩溃可能留下未登记引擎线程，本轮不承诺崩溃后原子恢复。
5. 草稿保存在本机，不提供跨设备同步；存储配额失败可见且阻止静默丢弃。账号以当前作者身份隔离草稿；多人云协作权限不是本轮范围。
