# 作品质量改进闭环

## 目标与边界

把创作使命和方法库落实为六项可用能力：作品审美记忆、创意兑现及亮点保护、隔离读者审阅、跨章质量观察、有限场景试写、匿名比较与作者反馈。复用现有任务/预算/正文修订/作者采用系统，不另建创作执行引擎。

不建立文学总分，不自动改写或采用作品，不承诺实验前已经提升文学质量。EternalLight 仅借鉴问题划分；不复制关键词评分、固定三方案或统一人物成长要求。

## 数据与流程

- Runtime 的作品质量笔记保存有界记录：偏好、兑现目标、保留亮点、跨章观察、试写。每项有来源、作者/模型身份、版本和状态。模型只能提建议；作者确认/撤回独立入口。
- 正文证据绑定已有作品修订和逐字引文：`current` 是当前稿件锚点，`reference` 是历史对照；有证据的记录至少包含一个当前锚点。历史修改前证据不会使整项偏好误判过期；当前锚点变化后明确标记失效，主智能体不得作为当前指导。试写单独存储，不能成为正文或 Canon。
- 偏好分作品与本次范围，作者可以添加、确认、撤回；从修改中提出偏好必须附修改前后证据，采用不自动推导为通用偏好。
- 创意兑现与保留亮点用目标记录、正文引文和不确定性支撑，配合已有 desiredOutcomes/expectedEffects 任务链；不以保存成功代替兑现。
- 跨章回看读取有来源的观察，按需要复查，不自动全书扫描；有意重复和风格演化不作硬错误。
- 试写由主智能体在当前授权和预算内完成，保存实际片段与共同问题；仅真实取舍才使用。作者可创建随机顺序的匿名比较，保留平局、弃权和理由，不隐藏失败或虚构用量。
- 独立 reader 任务只读冻结匿名阅读包并交回引文报告；不继承作者会话，不提供创作说明、候选映射或其他作品读取工具。资料完整性和审美结论分开。主 Agent 按需通过同 Work 决策自动启动，使用原任务剩余额度；UI 手动审阅是可选入口。详细编排见 AUTONOMOUS_QUALITY_DESIGN.md。
- UI 在作品信息中提供淡雅的“创作回看”入口：偏好、证据笔记、匿名比较、审阅状态。只显示真实状态；撤回保留历史，不删除作品。

## 安全与一致性

所有请求有严格字段、大小与数量限制。作品内 CAS/幂等防止重复提交，项目隔离和冻结修订验证位于 Native，不依赖提示词。模型读写仅向已有 advisory 根任务开放；reader 操作只开放包读取、报告和完成。工具、Runtime、Host、Renderer 一次性更新，无旧协议回退。

- 笔记与阅读包共用有界游标，作者每页最多 20 条、模型每页最多 1 条；可以继续读历史包，不将最新一页当全书结论。
- 模型读取在 Native 排除其他任务的 task-scope 笔记；作者侧仍保留审计历史。状态确认、撤回和反馈使用独立作者权限，模型不能代签。
- 笔记及报告限制为 6KB 转义记录，阅读包最多 30KB；阅读按 3KB UTF-8 页连续交付。未交付完整材料、哈希不符或伪造引文不能保存报告。交付不等于模型真的理解。
- Runtime 的通用 candidate 认证默认禁止 reader 使用普通作品接口，只有 quality 与 complete 入口接受 reader；不是仅靠 MCP 隐藏工具。
- Host 自动以空答案拒绝 reader 请求作者说明，且拒绝向该任务追加 steer 文本；不伪造作者选择。需要改变阅读材料时先停止，再建立新的阅读包。
- 模型报告和记事写入接入既有恢复操作回执；取消后不能继续读写。未确认的失败不会覆盖已经保存的笔记、正文或报告。
- 任务总览从已保存阅读包导出 `qualityReading` 交付证据，不冒充正文修订。读者中断后先核对保存结果；无报告时从创作回看显式重开全新任务与预算，不走会继承既有执行目标的普通 Work 续跑。
- 比较只隐藏候选身份并随机顺序，不保证作者本人不知道原稿。模型报告与作者反馈分开保存，显示选择分歧，不把重复反馈计为独立样本，也不建立文学总分。

## 实施前五角色自审

以下为同一执行者的五视角自审，不代表五名独立评审者。

- 架构专家：APPROVE。复用任务和保存源；质量记录是建议性旁路，不能写正文或确认事实。
- 技术专家 A：APPROVE WITH CONDITIONS。必须验证项目隔离、精确引文、过期、CAS/幂等、reader 工具隔离和新会话。
- 技术专家 B：APPROVE WITH CONDITIONS。测试覆盖六项能力及调用入口；不以纯 helper 测试声称完整运行时隔离。
- 产品经理：APPROVE。作者偏好可纠正撤回；试写和审阅按需，不制造强制流水线。
- UI/UX：APPROVE WITH CONDITIONS。清晰区分模型观察、作者确认、部分覆盖、已过期和阅读假设；保持低干扰布局和可访问状态。

## 验收与实施后复核

### 实际交付

| 能力 | 落地入口与约束 |
| --- | --- |
| 作品审美记忆 | `read_quality_notebook` / `record_quality_note`；作者确认、撤回、历史对照和当前证据，作品与本次范围分开 |
| 创意兑现、亮点保护 | goal / strength 与 observation 的 `relatesTo`、三态 verdict、实际稿件引文；复用已有 desiredOutcomes / expectedEffects |
| 隔离读者 | 同 Work `reviewQuality` 步骤、新会话、匿名冻结包；仅读包/报告/完成三个小说工具，主 Agent 按需调度，复用剩余额度 |
| 跨章观察 | 最多八处引用，可跨章关联；分页回看与过期标记，不自动全书扫描或把有意重复判成错误 |
| 有限试写 | 保存实际文本和共同问题，匿名比较真实候选；不自动写入章节、不强制三方案 |
| 作者反馈校准 | 保存作者选择及理由，保留与模型的分歧和用量 task 引用；主智能体可读报告作后续判断，不自动改变偏好或正文 |
