# 自主多智能体创作协作

## 淡雅协作状态行（UI实施前评审）

在对话执行过程旁默认显示每个子智能体的一行状态，按真实线程身份合并创建、等待、追问事件。小图标、灰色文字，无色块和卡片边框；点击展开任务与公开结果，原生details提供键盘操作，减少动态效果偏好下不播放动画。协议没有任务名时使用委派问题的首行，不猜测角色；没有排队事件不显示“等待资源”。工具调用完成不能视为子任务完成，本轮结束而子任务没有终态时标记状态未确认。保存有界公开元数据支持当前执行历史，保留既有总字节上限。

五角色评审：架构 APPROVE（Renderer派生状态，不建第二套执行系统）；技术A APPROVE（身份去重，不推断成功）；技术B APPROVE WITH CONDITIONS（真实事件归约、终态、历史和窄屏验证）；产品 APPROVE（默认可见、不抢正文）；UI/UX APPROVE（中性色、单行摘要、可展开详情和减少动效）。零兼容门禁 PASS，新增字段只属于当前公开执行快照，无数据库迁移。

## 资源调度修订（实施前评审）

以三个独立约束替代固定三个子任务：可配置子线程安全上限（默认16）、请求全局并发（默认4）、同一端点/凭据请求并发（默认2）。最多32个请求等待；总数有界。默认值是本地资源策略而非服务商配额声明。环境配置支持调整并发及按连接覆盖服务容量，运行期间冻结在 SessionPlan 中。

Codex 原生线程驻留、唤醒和已完成线程释放仍由内核管理。线程池满时主智能体维护尚未派发的工作清单，等待或复用已有子任务；不阻塞 spawn 工具等待槽位，避免父子依赖死锁。真实模型请求由 Engine 统一排队，排队期间不预占 token；token 被在途请求临时占用时等待结算，可永久确定不足时直接返回预算耗尽。取消、期限和异常均释放排队/执行名额。模型返回429时该服务容量减半，连续成功后逐步恢复到配置上限，不自动重放已发送请求。

五角色评审：架构 APPROVE（复用内核，请求调度属于 Engine）；技术A APPROVE WITH CONDITIONS（验证取消、释放、预算原子性）；技术B APPROVE WITH CONDITIONS（两种 bridge 入口一致，配置校验与实际排队集成）；产品 APPROVE（分工自主、成本受预算约束）；UI/UX APPROVE（不增加必须操作的开关，通过现有执行过程展示工作，资源策略可由环境配置）。零兼容门禁 PASS，不增加旧配置适配。实施后结果见文末。

## 目标与边界

复杂创作任务由主智能体自主拆分、并行分析、追问并汇总；简单任务直接完成。沿用 Codex 原生协作工具、会话树、驻留线程管理和 Agent Engine 能力认证，请求层单独执行资源调度。子任务数量按需决定，受可配置安全上限约束。认证通过自动启用，认证不足继续单智能体工作，不伪造协作结果。模型选择处明确显示协作能力是否已验证。

子任务可以是结构、一致性、人物动机、证据检索或方案比较，不限于预置角色。父任务明确范围、故事上下文、问题和交付要求；子任务只读，返回证据、推断、不确定性及建议。主智能体负责检查分歧并通过已有候选/采纳流程写入。任务取消、预算和生命周期沿用现有内核；不在界面根据一个工具调用结束就宣布所有子任务结束。

## 实施

1. 将协作政策集中为产品指令，编译到当前内核实际读取的 `root_agent_usage_hint_text`；通过 `multi_agent_mode_hint_text` 明确主智能体主动委派，避免非 Ultra 推理档位默认只允许显式委派。政策与并发限制加入资格上下文摘要，防止指令变化继续使用旧认证。删除编译器的旧 `usage_hint_text` 输出，不保留双轨配置。
2. 多章审查、多角度规划与独立原因分析默认优先委派；有依赖的步骤保持顺序，避免重复工作。失败时可缩小范围重试或由主智能体接手，最终交付说明未完成项。
3. 模型列表展示认证推导的协作状态；协作事件保留任务、各子任务终态及公开结果，限制输出长度，不读取私人推理。
4. 验证默认政策、认证门禁、公开事件结果、现有真实内核委派集成及前端构建。

## 资源策略配置与修订复核

通过启动环境 `NOVEL_CODEX_RESOURCE_POLICY` 设置 JSON，例如：

```json
{"maxActiveChildren":24,"maxConcurrentRequests":6,"maxRequestsPerProvider":3,"maxQueuedRequests":32,"connectionLimits":{"deepseek-flash":2}}
```

未指定字段使用本地默认策略：16个子线程安全上限、4个全局在途请求、同服务2个在途请求、32个等待请求。各数字可配置1–64；不是自动探测到的服务商额度。未知字段、非整数或越界配置会拒绝创建会话。配置和政策实现进入认证摘要，改动后重新验证连接、建立新会话。主智能体会收到本会话的具体容量提示。

同一端点与凭据引用的连接共享服务并发，存在多个连接配额时取最小值。队列允许其他服务绕过已饱和服务。请求到达至完成受现有请求超时及任务期限约束。429减半服务窗口，四次完整成功恢复一个名额，最多恢复至设置上限；未增加自动重放。预算等待不会新增账目，也不会在持久化预算中反复写入不变状态。永久不足、未知已消费用量、任务取消等仍按原有安全语义终止。

线程上限按子线程定义，写入 Codex 总线程配置时加一计入主线程。模型维护尚未派发工作的清单；引擎排队的是实际模型请求，没有实现新的持久化子任务队列。操作系统异常退出的任务恢复仍使用现有恢复机制。
