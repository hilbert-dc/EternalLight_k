# 规划消费叙事承诺提案

## 目标

继续 S3 自动创作闭环，使提取报告里的未建立提案参与后续 Brief / Outline / 滚动 Plan / 规划审阅。复用任务绑定的 Context Pack，不建立第二数据库、执行器、供应商调用或自动确认路径。

## 契约与实施计划

- 在同一 SQLite 读快照里，读取 main 当前选中的提取报告，先核验绑定正文仍是当前快照成员，再应用任务正文范围。滚动规划只能看到起始章之前的报告；未来、过期、其他作品报告不能占候选额度。
- 新增独立 `candidateCommitmentProposals` 区，不混入 `relevantCommitments`。每项保留 chapterId、chapterNumber、reportRevisionId、sourceRevisionId、批次局部 proposalId、摘要、标准和精确证据；明确 `candidateProposal`、未建立、未确认、非 Canon、不证明兑现。跨批次同名 ID 不合并。
- 在当前快照已经有对应 extractionOrigin 的独立对象时，原提案不再重复进入候选区；独立对象继续走已有承诺投影。作者之后的摘要、状态及证据不能被旧提案覆盖，也不回填或自动修改报告。
- 选择最近正文优先，最多 12 项、8 KB；单项最多 2 KB，最多检查 101 项授权候选。整项过大则省略并报告预算缺口，不截断原文引证或悄悄补全字段。数据库选择、条数、整包预算均暴露覆盖未知，不宣称全部伏笔已召回。
- 提案区只对上述规划操作开放，Writer、知识提取、承诺提取、场景评估不获额外披露。权限来自持久任务，不从 purpose 字符串扩大范围。Context Pack 总预算先裁剪低优先级提案，尽量保留最近的一项并移除其他可选材料；冻结任务和必需来源仍超预算时可移除最后一项。每次移除同步更新 includedEntries、missingScope、truncationReasons 和内容摘要，不让提案挤掉必要输入。
- 首先落 Rust 选择与隔离测试，再接 Context Pack/预算和冻结规划说明；真实 HTTP 三章和续作测试确认后续规划能看到当前报告及正确正文来源。文档同步记录真实验证，不以 fixture 宣称供应商文学质量或 S1–S5 全部完成。

## 实施者五视角自检

依用户要求单人推进，不召开评审或使用子 Agent。架构：复用修订权威和上下文链；技术 A：读快照、来源、范围、作者决议及硬预算；技术 B：真实仓储、Runtime 与连续生成回归；产品：无需作者逐章手工建立才能参考提案，作者确认仍独立；UX：不新增打扰写作的操作，模型说明区分候选与正式设定。零兼容门禁：无旧字段 fallback、双轨、回填、迁移、供应商专属逻辑或上游内核修改。

## 验收与剩余边界

已实现私有 Rust 提案选择模块、任务绑定装配、Context Pack 总预算裁剪及宿主来源说明。17 项专项仓储/Runtime 测试和 6 项任务交接测试通过，其中新增 4 项提案投影测试、1 项真实 HTTP 预算场景，扩展 7 项连续生成测试覆盖后续第二、三章规划及第四章续作。作者建立后排除旧提案、改文失效、未来报告先过滤后限额、批次身份不合并、整项超预算省略、总预算裁剪计数与内容哈希均有实际执行证据。

预算回归发现较大的工作知识投影可能挤掉全部提案，裁剪策略现优先保留最近一项，直到冻结任务/必需输入需要其空间为止；真实 HTTP 用例覆盖这个竞争，不把“字段存在但永远为空”冒充规划接通。没有降低任务完成或来源校验门禁。

最终 `CARGO_NET_OFFLINE=true npm run verify` 退出 0：构建、两轮 Rust 工作区测试、180 项引擎、2 项真实 Codex 委派集成、7 项发布门禁、144 项 Agent/宿主、11 项 UI 全部通过。native 全工作区全部 targets 的严格 Clippy（`-D warnings`）通过；工程边界 `strictReady=true`。既有前端大体积 chunk 警告仍存在。上述模型回环采用受控端点，不是供应商文学质量认证。

实施后五视角自检与零兼容门禁通过：唯一任务/修订权威未变，当前来源与范围先于限额，作者建立与确认未被自动提案替代，覆盖和未知清晰；无新 schema、依赖、历史兼容或上游内核修改。领域投影及隔离测试、Runtime 装配/预算及连续生成测试可按这两层分别审阅。

规划收到提案不证明模型必然采用，也不证明语义召回、兑现判断、跨批次语义合并、真实供应商质量、Windows 实机或完整 S1–S5 达标。包含大量提取报告及独立承诺的新投影规模/排序质量仍需单独基准，已有百万字字面检索数字不能替代该测量；承诺的世界状态、语义兑现及依赖反馈继续推进。
