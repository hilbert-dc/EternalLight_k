# 按模型动态选择推理强度

目标：作者在模型旁自行调档，执行期间仍可操作。界面只显示当前选择，失败才提示原因，不增加“已生效／待生效”标签。最低开放档满足产品准入基线，不等于供应商 API 最低值；不同模型独立定义选项。

## 边界和合同

- 产品受控策略提供每个模型可选集合、默认值和显示名称。Renderer 展示 Host 返回的集合，不独立判断模型能力。
- Host 持久化作者选择；每个后续请求经受信回调取得当前档位。同模型子请求使用该选择，其他模型按其自身策略。调整不注入作者消息，不中断当前请求，不重建任务、租约或预算。
- Engine 校验回调只能指定该连接允许集合中的 reasoningEffort，不能改模型、端点、工具或权限。取一次快照用于一次请求；在途请求保持原值。无回调时保持原请求合同，回调失败拒绝新请求，不静默降档。
- 连接定义冻结默认值和允许集合；选择集合内另一档不改变资格指纹，变更集合/协议/默认值仍使资格失效。不能借参数选择扩大路由或权限。
- 偏好保存在 Host 原子配置文件；Native 原 Work、正文和费用账本不变。切换模型仍经过原有准入门禁，调档与换模型分开。
- 不修改 Codex Core。已核对当前公开 turn/steer 不接受 effort，turn/start 要求非空输入，不能伪造输入来改设置。复用已有 Engine 模型传输边界，配置由受信 Host 提供。

## 状态与验证

| 事实 | 行为 | 副作用与证据 |
| --- | --- | --- |
| 原请求已经发送，新档位保存成功 | 后续请求使用新值 | 原请求不重发；同一 Work/预算/租约 |
| 请求明确指定较低值，作者已选择更高档 | 受信选择覆盖请求参数 | 不受模型输出或作者正文中的伪配置影响 |
| 不在允许集合／回调失败 | 拒绝该新请求 | 不发给供应商、不预留费用，不回退默认档 |
| 持久化失败／模型身份已改变 | 保留此前选择，显示错误 | 不产生配置部分提交 |
| 同模型子任务／其他模型子任务 | 前者用当前档；后者用目标模型策略 | 原路由和协作准入照常检查 |
