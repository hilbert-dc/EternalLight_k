# 长篇创作上下文与证据架构

创作质量是首要目标，节省 token 是服从质量的工程原则。在作者意图、授权与实际资源条件内追求最佳创作效果，保留必要的原文阅读、探索、比较、修订和独立核验，消除无效探索、重复传递和协议返工。优化单位是完成一次创作目标的全过程，而非单次响应长度。本文是实施主记录；尚未取得的验证不记为完成。

## 决策优先级

不能把少用 token 本身作为创作成功，也不能仅因索引、摘要或局部片段更便宜而强制替代必要原文。质量存在未解决风险时优先补足证据与核验；节省方案尚未证明保持质量时，不升级为强制默认路径。这里的质量以作者追求的效果及当前作品为准，不强加统一文学公式，也不以无限润色替代完成。

即使 token 非常便宜，版本、来源、人物认知、修改依赖与原文定位仍服务于可靠创作。语义索引是否值得建设取决于其质量、速度和维护收益；它是可重建、可绕过的辅助资料，不是创作准入条件。若直接全文阅读在某类任务上更准确、更快或总成本更低，应允许替代相应索引路线。工程不得把当前价格假设固化为固定片长、固定阅读章数或全书建模义务。

## 问题与决策

第 52 章既有审计确认 90 次有用量回执的请求累计 5,166,243 token，其中输入 5,004,370、缓存输入 3,876,224、输出 161,873；缓存属于输入，推理属于输出。独立评审及其子任务占 3,806,550。另有一次无用量回执请求，其预留推算不计入已确认消耗。这不是五百万份不同故事材料，也不能把评审用量全判为浪费。

根因包含设计缺口与实现缺陷：问题所需证据难以直接读取，导致多轮探索；探索历史在后续推理及全历史子任务中重复携带；顺序扫描与语义召回容易混淆；局部片段缺少完整场景扩读。单独缩短片段、增大批次、提高缓存率或降低压缩阈值均不足以解决。

采用三层目标：准确且可回查的故事工作环境，按问题组合的证据读取，以及任务上下文生命周期。模型决定创作、查询和语义判断；工程保证身份、授权、版本、原文坐标、持久状态与实际计量。不存在一条固定的最佳阅读路线，也不强制每章全书建模或多代理协作。

## 目标架构

### 原文与叙事依赖

正文修订是原文权威。复用现有人物、知识状态、关系、承诺和来源证据模型，不另建全书事实库。事实、人物说法、推测、作者规划分别保留；人物认知同时受观察者、故事时间和揭示章节约束。语义关系须关联原文版本、证据和不确定性；源版本变化后不能沿用失效结论。没有关系不证明不存在，未建模不能阻断已获准的原文阅读。

例如“甲认出凶手”可追溯“判断依据—曾见物证—目击条件—物证转手—甲是否获知”。索引负责定位，原场景负责支持判断。语气、隐喻和文学呼应不由结构化图谱代替。

### 问题驱动的读取

复用 query_story 的实体、状态、关系与词面查询，并清楚标注它们的证明范围。当前 ModelSemantic 是已召回候选的模型重排，不能称为向量召回；顺序 passages 也不是相关性搜索。

已知来源时直接读取；未知来源时组合关系与原文检索。定位到片段后能按场景读取完整上下文，保留版本和 Unicode 坐标。篇首篇末批量片段仅用于明确的边界问题。模型可扩大到整章或多章，不设全局固定片长作为理解边界。传输分页仅保护单次载荷，可续读，不限制任务总阅读量。

已知多份来源允许批量组织读取，返回重叠证据应可识别。精确文本重复由确定性查询支持，语义重复仍由模型判断。任何全局否定都必须区分授权范围、扫描覆盖和语义充分性。

### 上下文生命周期与协作

复用 Native 的任务、冻结来源、质量笔记和读取记录；Core 负责上下文压缩与窗口管理，Engine 负责累计用量。目录、已返回记录、当前模型仍可见的原文是不同状态；已返回不等于当前记得，也不等于理解。

阶段交接携带目标、作者要求、必要状态、未解决问题及证据引用，不要求复制全部搜索过程。子任务按问题选择独立上下文或继承上下文；继承全历史不是默认的独立核验保障。父任务核对关键证据及报告版本，不机械重做子任务全部探索。独立评审不能仅接受写作者结论。

当前已有首次工作集之后增长维护、下一回合开始前的历史维护与按需恢复原文；先验证这些生产接线，不盲目再降阈值。缺失上下文应能从原文恢复，不能通过摘要伪造完整阅读。

### 用量与质量验收

采用质量优先的决策顺序，而非把质量和 token 加权后互相抵消：先判断读取与核验能力是否满足本次作者目标，再在没有已知质量退化的方案中比较成本和耗时。能够改善创作质量的必要额外消耗应保留。没有文学质量对照时，只能宣称合同正确或提供了新的可选能力，不能宣称减少阅读的默认策略已获验收。

读取深度由证据问题与创作效果决定。完整原文、整章/多章扩读、独立评审和已有标准均不因效率目标被撤销。压缩验收同时检查关键细节、来源定位、恢复阅读与错误判断成本；维护阈值是待校准参数，不是最佳质量的已证结论。索引、短片段与整段阅读并存为同一来源的不同操作，不是历史兼容双轨。

累计输入、缓存输入、未缓存输入、输出、推理子集和未知预留分别报告。没有报价不计算实际金额；没有完整可比样本不声明整章节节省比例。记录请求数、阶段、子任务、错误返工、压缩及恢复读取；字节减少不等于计费 token 减少。

优先离线合同与既有轨迹审计；不为测量新增付费模型请求。自然创作样本同时观察漏证据、错误结论、正文与标准保持、独立核验、总费用与耗时。保存、核验、交付、发布维持各自条件。
