自审，五视角：架构/技术A/技术B/产品/UI 均 APPROVE WITH CONDITIONS，条件为对应回归通过且不声称真实模型已复验。

Native WorkInterludes 拥有返回与完成事实（B03/B05/B06）；Host 只消费回执。已完成父步骤和插问关闭后若 Work 已完成，不需要未来推理预算；仍有未完成步骤、嵌套插问或生成任务时保留原预算准入。输入、未结算、暂停、身份、版本校验不变。交易内先计算返回结果，预算拒绝整笔回滚，无部分返回。

| 条件 | 结果 | 副作用/后续 |
| --- | --- | --- |
| 已完成父任务和插问、已结算但请求耗尽 | 允许关闭插问并投影 completed | 无模型调用/无新预算 |
| 父任务仍需执行、额度耗尽 | 拒绝并回滚 | 保留插问 |
| 暂停/输入变更/未结算/错误身份 | 原有拒绝 | 不扩大授权 |

验收脚本负责观察与测试范围：生成提案经公开 generateWork 批准（仅隔离虚构作品且同场景剩余额度），读取实际生成结果；每项先等待后台执行和用量终态，超时明确停止所有本次项目执行并记录清理结果，不把探针退出当作产品失败。禁止无界追加请求，token=null。脚本职责不进入生产创作层，不更改模型决策。

用量未知维持真实记录；已观察到原 attempt 失败后的自动续接，并没有证据授权删账或放宽 Engine 同 attempt 重复派发门禁。本轮先验证 Native 既有“无 token 上限、已终止并登记历史未知用量”恢复合同，明确尚缺真实供应商复验。

计划：Native 插问耗尽返回回归及原拒绝边界；Host 插问测试；脚本公共 API 生命周期受控回归；architecture:check。零兼容 PASS。本轮无付费模型调用。

构建准备中发现并修复同工作区模块拆分后的编译阻断：context_read_api::read_context 为 pub(crate)，其 ContextQuery 仍私有，server 路由绑定报 private type。仅将参数类型设为 pub(crate)，字段与 HTTP 合同不变，归属 Runtime/B01；五视角自审批准这一必要同步，不引入兼容。

## 已实施

- Native 将返回后的完成状态计算与预算检查放在同一事务内：仅 computed status=completed 可免去未来执行额度检查；其他状态保持拒绝，并回滚返回记录/步骤变化。输入与未结算检查仍在前面。
- 新增耗尽请求额度的正/负回归，包括完整回滚、重复命令及不新增步骤。
- 验收观察器读取公开 listExecutions、listWorkTasks、agent.status.executionHealth；既等待在途结算，也等待已安排的后台重试，不能仅凭前台 promise 结束或短暂无请求判定完成。
- 正常与异常收尾均先暂停本次项目的 durable Work，再中断精确 requestId，读取稳定终态与最终 Engine 回执；超时/未知明确记录。原始场景结果与 probeInitiatedStop 清理记录分开，报告原子写入。
- 生成提案使用 UI 相同 generateWork 参数，仅批准本次虚构作品的一章范围。初始生成预算从已终止 attempt 的真实 Engine receipts 计算剩余请求数，token=null；来源变化、未结算回执、重复或耗尽额度均不派发。不会采用或发布。
- 测试入口新增 task-live-lifecycle.test.mjs，启动器在缺失报告、清理失败、未验收项目或子进程异常时非零退出。
- 依据真实日志将中途变更首个故障精确记录为 bridge response closed，后续 task_provider_usage_unknown 是保护错误；未将未知费用清零。Runtime 的原 Work 续接测试扩充为 maxRequests=6/maxTokens=null，与本轮授权形状一致，验证剩余请求递减、原未知账单不变、不重复收费。
