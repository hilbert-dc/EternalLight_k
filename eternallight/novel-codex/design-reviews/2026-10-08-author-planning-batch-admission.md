# 原作者规划动作的准入与接力

日期：2026-10-08。失败证据：`/tmp/autonomous-v3-work-outline-diagnostic-20261008.log`。

Host 对同一作者输入登记的简报、大纲逐项“批准后立即执行”。简报保存使源变化；尚未批准的大纲随后被批准，但当前 Native 已把这种未尝试规划交回同 Work 决策，因此直接 claim 失败。不能把这一失败包装为未尝试，也不能降低来源或许可校验。

目标：本轮已经明确请求的多个规划候选先逐项通过原 Native 作者准入，任何一次准入失败都不开始模型。首次实际执行改变来源后，Host 停止直接领取后续规划，交回已有同 Work 模型决策。模型可保留、调整顺序或放弃方法；Native 只允许真实已批准、未尝试、原范围与预算内的行动引用重用。该方案不增加作者输入、不改作品采用边界。

## 五视角预审

| 视角 | 条件 |
| --- | --- |
| 架构 | 原 Action/Step/Work 和 Native 许可是唯一权威；审批次序不是创作阶段流水线。 |
| 技术 A | 全部来源/归属与当前可用性检查在执行前；中途暂停或准入失败不派发；实际产物改变来源后不直接 claim 原规划。 |
| 技术 B | 仅改变当前 Host 规划准入顺序，同步真实 Native 与 Host 测试；没有旧字段兼容、假回执或人工追加许可。 |
| 产品 | 一次作者请求可完成简报和大纲，不因内部源刷新要求用户再输入；不自动扩大请求或额度。 |
| UI/UX | 继续显示实际保存结果，后续决策由模型说明；无需新增审批面板或技术标签。 |

五视角为职责审查，不表示五位独立人员。零兼容预审：PASS。故事分析等其他候选的原源变化停止边界保持。
