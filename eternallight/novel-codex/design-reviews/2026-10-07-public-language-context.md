# 公开对话语言与当前会话策略：实施前评审

日期：2026-10-07。按本工程模板完成五个视角复核，不代表五位独立人员审阅。

## 目标与证据

真实中文作者任务中，Writer 与独立评估任务的公开进度出现英文。现有语言规则确实位于应用的 developer 配置及 application 上下文；不能将已送达规则被模型忽略谎称为配置缺失，也不能以工程测试声称真实模型完全遵守。

本次修复将公开语言规则置于持久应用职责首位，并用等价简明中文表达应用职责；新建与恢复会话显式绑定当前产品 developer 策略。每个托管只读角色明确共享语言约束。作者仍可用自然语言要求另一种交流语言；正文、引文、代码、工具字段和历史输出保留原文。不检测“继续”等关键词，不通过替换模型输出假装遵守。

## 边界与验收

- 只修改 Host 产品策略、当前 app-server 会话绑定、角色配置与定向测试，不修改 Codex 内核、Native 领域状态、实际小说或数据库，不重启实机。
- 使用当前 app-server `thread/start.developerInstructions` 与 `thread/resume.developerInstructions` 已声明字段。真实 app-server 测试覆盖初次调用、恢复、内部 Writer/Critic、同一线程压缩及英文正文/作者明确切换交流语言。
- 保留 4KiB/1000 保守 tokens 的持久 developer 准入，以及每次完整文本 38KB/9000 tokens 准入；不新增截断或扩大额度。
- 工程测试只证明策略送达、压缩恢复及身份/预算不变；真实模型语言遵循仍由实机验收。

## 零兼容门禁

未新增版本检测、旧字段 fallback、迁移、回填、双读双写或降级。当前角色源码与托管配置一次更新；当前接口/fixture/测试同步修改。未知写入、权限和模型预算仍由既有 Runtime/Engine 校验。
