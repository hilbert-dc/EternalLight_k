# 作者任务面板：有界阅读进度

## 目标与边界

在现有 WorkTask → WorkStep → Attempt 链中展示原文阅读检查点，作者可以看见暂停、恢复和中断前的进展。不另建调度器，不增加模型工具，不放宽根 Agent 的能力凭证或子 Agent 边界，不把读取页数当作理解质量或任务完成。

只支持当前契约。WorkStep 必须返回 `readingProgress`，无检查点时为 `null`，同步修改 Rust、TypeScript、fixture、测试及现行架构文档；无升级、双读或旧字段 fallback。

## 领域投影

- `current`：仅返回检查点版本、已确认页数、去重原文字符数以及 `reading` / `acknowledgedEnd` / `budgetExhausted` 遍历状态。
- `stale`：原输入或授权来源范围变化。不返回计数、摘要或恢复位置。
- `unavailable`：检查点完整性或所属尝试绑定不可验证。不伪造进度，仍允许作者查看和取消任务。数据库读错误继续报错，不吞掉存储故障。
- `null`：尚无检查点，不渲染占位进度。

作者只读投影不要求 Attempt 仍运行或能力未过期；它验证原 Task 确实属于此项目的此 WorkStep，并复用冻结输入检查、TaskQueryScope 及原文来源水位。任务列表、详情、按 Attempt 查找和控制回执在各自既有 SQLite 事务内读取，不新增事务，不在提交后重读控制结果。读取不写版本、不创建回执、不刷新调用预算。分页是交互浏览，不是跨页不可变进度快照；每页仍是同一事务快照。

根 MCP 的阅读恢复仍要求运行中任务与父任务、有效凭证及当前输入。作者进度绝不包含模型摘要、查询计划、游标、线程身份、凭证、回执或完整原文。暂停/取消/完成保留历史可核验计数，不承诺这些终态仍可恢复。

## 交互

在每个步骤下显示紧凑阅读条，无百分比、无全书理解进度条：

- 原文阅读进度：已确认 N 页原文 · M 字符（标题不冒充执行器仍在运行）。
- 范围末尾：当前阅读范围已遍历；不代表全书或内容理解完成。
- 达到有限页数预算：检查点预算已用完；不承诺继续或重置预算。
- 来源变化：原文来源已变化，旧阅读进度不再有效。
- 不可验证：阅读记录无法校验，不显示进度。

始终说明理解完整性尚未验证。复用现有任务刷新、控制和禁用原因；不以阅读状态重新推导恢复权限。现有列表没有运行中轮询，补上与工作区一致的 1.5 秒刷新，仅 Agent 运行时启用，第一页轮询只有一项读取在途、不重叠。运行中刷新重读第一页（历史分页不是实时审计快照），页加载用既有 epoch 拒绝迟到响应；停止或切换作品时清理定时器及旧响应，作品切换立即清除旧任务。文本状态可读，不只靠颜色；长文本换行，窄宽度不溢出，不高频 live 宣告计数。
