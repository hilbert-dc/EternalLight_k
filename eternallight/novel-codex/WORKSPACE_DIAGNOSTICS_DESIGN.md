# 作者工作区诊断分层

## 目标与边界

S5 后台校验应可理解、可控制，但不能让作者先浏览六项维护卡片才能创作。六类 Rust 校验任务仍是唯一执行权威；本阶段只整理其客户端展示与异步状态，不新增调度器、诊断缓存、模型调用或修复正式内容的路径。

## 当前版本契约

- 章节工作区以一个默认折叠的“系统诊断”入口替代六张置顶卡片。内部六项面板始终挂载，折叠不取消任务或停止现有有界轮询。
- 摘要分别显示读取中、进行中、暂停及需要处理的数量。失败、来源过期、读取失败和完成但未经核验的结果仍可见；没有报告不能显示“一致”，六项局部结果不组合成全局知识认证。
- 展开由作者控制；异常不自动抢焦点或展开。告警摘要可被读屏识别，运行进度不每秒制造读屏打扰。章节知识待分析等创作屏障仍留在正文附近，不藏入诊断。
- 每个面板按作品与校验类别挂载独立生命周期。切换作品或卸载后，迟到读取和操作不得污染新作品；不复用上一个作品的错误或 busy 状态。返回其他作品的报告拒绝显示。
- 操作使用同步 in-flight 门禁，阻止同一渲染帧重复点击。读取与操作仍使用现有版本、作品和任务 API；操作结果后的状态刷新不能被旧轮询覆盖。一次读取恢复成功清除旧的传输错误，但不清除报告本身的失败或不一致。
- 每个面板最多一项读取在途；刷新突发合并为读取完成后的最新请求，不由 effect 重建放大并发。读取与操作分开计代次，操作期间刷新不丢弃有效操作结果。操作失败保留到下一次明确操作，不被一次成功读取消音；读取失败提供只读重试，不通过启动新校验恢复连接。
- 不执行历史兼容、数据升级、旧字段 fallback 或双轨 UI，当前调用方与 fixture 一次更新。

## 单人五视角实施前自检

按用户要求由单人实施，不组织评审会议。架构：展示汇总不是新权威；技术 A：生命周期、迟到响应、重复点击、轮询与状态恢复；技术 B：真实 Electron 回归和当前类型/调用方一致；产品：作者先看到正文，异常不消失；UX：键盘可折叠入口、清楚局部范围、默认减少维护噪声。结论：按上述契约实施，不能以 UI mock 代替原生审计的正确性证明。

## 验收

1. 六项面板默认在一个折叠组中，正文编辑区不被六卡片推离首屏；展开可使用原开始/暂停/恢复/取消入口。
2. 折叠时执行任务继续读取新状态，失败或不一致反映在外层摘要；输入、焦点与未保存正文不受诊断变化影响。
3. 成功读取清除传输错误；错误仍有实际报告时不伪装成校验成功；无报告、部分运行和完成但未经核验均诚实显示。
4. 快速重复开始只发起一次操作；旧读取或旧作品的迟到操作不覆盖当前状态。
5. 构建、隔离 Electron UI、完整现有 UI 回归通过，并检查实际渲染截图。保留原生审计/校验已有验证，不据本阶段宣称 S1–S5 达成。

## 实施后记录

已实现 WorkspaceDiagnostics 与六类局部状态汇总，章节工作区一次切换到默认折叠入口。内部面板保留原 API、版本控制与运行中轮询；同帧重复操作使用同步门禁，读取突发合并为最多一项在途请求。作品切换以 keyed 生命周期隔离迟到结果，跨作品报告拒绝显示。

读取传输错误与操作错误分别保存：成功读取只恢复连接状态，不掩盖被拒绝的开始/暂停等操作。只读重试不创建校验任务；旧报告即使曾 verifiedConsistent，也不能在读取失败、来源过期或未完成核验时显示为当前“一致”。折叠摘要保留异常、运行和暂停提示，不合成全局认证。

最终当前源码验证：`npm run build` 退出 0，`npm run test:ui` 全部 12 项通过；另行执行真实 CreativeWorkspaceView 的隔离 Electron 回归并检查截图，默认入口折叠、正文编辑区在首屏，未保存输入和焦点在后台报告变化后保留。新增回归覆盖重复点击、刷新合并、旧读取、迟到跨作品操作、只读恢复、操作错误不被成功读取消音、来源过期和伪造跨作品报告。Electron 为实际渲染，传输使用 fixture；不将它称为供应商或 Rust 审计端到端验证。本轮未修改 Rust 或上游 Codex 内核，未重复宣称上一阶段的全量 native/引擎验证覆盖本轮前端代码。Vite 大包体警告仍存在。

实施后单人五视角复核：架构没有第二任务权威；技术 A 读取与操作代次分开且在途有界；技术 B 当前调用方与 fixture 同步、构建及全部 UI 回归通过；产品先呈现正文并保留异常可见性；UX 原生键盘折叠、不自动展开或抢焦点。没有组织独立专家评审。

剩余真实供应商连续创作、人工文学/知识金标、完整语义/影响召回及 Windows 实机须各自验收，本阶段不缩减这些要求。已检查的长篇基准只证明合成数据的字面锚点召回与派生索引重建；模型接入认证也不是小说领域的语义或文学质量评估。下一阶段优先补齐这些领域验收与能力，不继续用展示层整理替代核心目标。
