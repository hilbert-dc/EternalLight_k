# Writer 绑定章纲与执行依据

2026-09-27 · S3/C03–C05 · 实施者自检（非独立评审）。

## 问题与决策

链路核查发现原 Context Pack 从规划头按章号寻找 Writer 指引；该头可能不是
章节绑定的不可变规划版本。原工作区把 `writerProjection` 固定返回 null，导致作者预览
无法可靠获得绑定章纲的 POV/世界时间。当前版本直接改正，不增加兼容层。

Writer 的计划依据只来自 `ChapterBinding.planRevisionId/chapterPlanId`，
校验唯一条目与章号。无绑定的独立章节不借用同号规划；损坏绑定返回错误，
不得退回当前规划头。作者工作区的公开投影也来自同一绑定版本。Renderer
不再用工作规划头或已采用规划头替代绑定投影，并核对预览返回的 POV/时间。
Scene 前缀裁剪、来源围栏、预算、候选权限和原调度通道保持不变。

补充执行门禁：自动 Draft 动作必须携带绑定章纲的 POV/世界时间，而非固定
生成无 POV 的目标；认领事务重新读取同一绑定版本核对目标，遗漏/替换受限
POV 或时间必须整体拒绝且不计调用、不留下工作步骤。共享读取放入小说
story-core（不是上游 Codex 内核），Runtime 与 authoring 复用；精确核验
作品、对象种类和源修订，删除 Runtime 的重复读取实现。
自动运行的 Draft 认领同时核对整章范围、章节位置及场景起点；局部修订仍
走其独立任务契约，不能冒用自动 Draft 步骤的预算和完成条件。模型规划的
POV 必须为有界非空字符串或未指定，世界时间必须为整数或未指定；非法
字段在生成计划写入时拒绝，已损坏的绑定来源也必须停止读取而非扩大可见性。
作者关联与手动/自动建章也执行同一位置字段校验，避免把非法候选绑定为
执行依据。拒绝发生在修改关联、作品版本或运行状态之前。

本变更不定义作者工作基线等价性，也不更改正文选择政策；仅修正章纲依据。
跨版本规划更新仍须显式重新关联与重规划，不自动改章、采用候选或重置预算。

## 验证

在真实 Router/SQLite 改稿与关联旅程中验证：更新规划候选头后、作者确认
重新关联前，预览仍使用旧绑定；重新关联后工作区投影与 Writer 任务上下文
共同使用新绑定。比较实际内容与来源 ID，保持原正文、旧凭据围栏和预算
断言。运行相关 Runtime 回归、严格 lint、前端构建及真实父工作区回归。
此证据不代替真实供应商、文学效果、完整 App 或 Windows 验收。

桌面联合旅程使用生产 CreativeWorkspaceView、preload、受信写 IPC 和真实
Rust Runtime/临时 SQLite：新规划头已保存但尚未确认关联时，预览仍显示旧
章纲的林夕/时间 10；确认后同一父工作区显示新指引及张衡/时间 20，新任务
继承相同位置，再沿建模、承诺提取、评估与检查接续。快照覆盖两个位置状态，
而非只观察后端响应。fixture 仍替换顶层导航、启动/读取注册及模型输出；
未验证完整 App 或真实 Codex/MCP 供应商执行。
